\section{Resumo}\label{resumo}

Nesta aula iremos simular o processo de amostragem de uma comunidade
biológica utilizando diferentes tipos de balas como organismos. Vocês
serão responsáveis por coletar, identificar e registrar os dados da
forma que julgarem mais adequada. A atividade tem como objetivo
evidenciar que dados ecológicos não surgem prontos para análise, mas são
construídos a partir de decisões tomadas durante a observação,
identificação e organização das informações.

\section{Objetivos da aula}\label{objetivos-da-aula}

Ao final desta aula, você deverá ser capaz de:

\begin{itemize}
\tightlist
\item
  compreender o conceito de unidade amostral;
\end{itemize}

\begin{itemize}
\item
  reconhecer a influência do esforço amostral sobre os resultados
  obtidos;
\item
  identificar problemas de padronização na coleta e registro de dados;
\item
  compreender que dados ecológicos são construídos antes de serem
  analisados;
\item
  reconhecer a importância de protocolos padronizados de amostragem e
  identificação.
\end{itemize}

\section{Conexão com a
Conservação}\label{conexuxe3o-com-a-conservauxe7uxe3o}

Levantamentos e monitoramentos de biodiversidade dependem da coleta
padronizada de informações biológicas. Antes de qualquer análise
estatística, os pesquisadores precisam identificar organismos, registrar
observações e organizar bancos de dados consistentes. Erros nessa etapa
podem comprometer todas as análises subsequentes.

\section{Atividade prática}\label{atividade-pruxe1tica}

Parte 1 - Caracterização de uma comunidade biológica

\begin{tcolorbox}[enhanced jigsaw, arc=.35mm, bottomrule=.15mm, bottomtitle=1mm, breakable, colback=white, colbacktitle=quarto-callout-tip-color!10!white, colframe=quarto-callout-tip-color-frame, coltitle=black, left=2mm, leftrule=.75mm, opacityback=0, opacitybacktitle=0.6, rightrule=.15mm, title=\textcolor{quarto-callout-tip-color}{\faLightbulb}\hspace{0.5em}{Tip}, titlerule=0mm, toprule=.15mm, toptitle=1mm]

Nesta atividade iremos simular a amostragem de uma comunidade biológica
utilizando diferentes tipos de balas como organismos.

A turma será dividida em grupos. Cada grupo será responsável por coletar
uma amostra da comunidade, identificar os organismos encontrados e
registrar os dados obtidos.

O objetivo da atividade é caracterizar a composição da comunidade
presente na área amostrada.

Preparando o ambiente no R

\end{tcolorbox}

Procedimentos

\begin{tcolorbox}[enhanced jigsaw, arc=.35mm, bottomrule=.15mm, bottomtitle=1mm, breakable, colback=white, colbacktitle=quarto-callout-tip-color!10!white, colframe=quarto-callout-tip-color-frame, coltitle=black, left=2mm, leftrule=.75mm, opacityback=0, opacitybacktitle=0.6, rightrule=.15mm, title=\textcolor{quarto-callout-tip-color}{\faLightbulb}\hspace{0.5em}{Tip}, titlerule=0mm, toprule=.15mm, toptitle=1mm]

\begin{itemize}
\item
  Cada grupo deverá coletar uma amostra da comunidade de balas
  disponível.
\item
  Após a coleta, os integrantes do grupo deverão separar os organismos
  encontrados em categorias (espécies) que considerem adequadas.
\item
  Cada grupo deverá registrar os dados coletados da forma que julgar
  mais apropriada.
\item
  Os dados deverão ser entregues através do Google Classroom ao final da
  atividade no formato de planilha.
\end{itemize}

\end{tcolorbox}

*Importante*

\begin{tcolorbox}[enhanced jigsaw, arc=.35mm, bottomrule=.15mm, bottomtitle=1mm, breakable, colback=white, colbacktitle=quarto-callout-tip-color!10!white, colframe=quarto-callout-tip-color-frame, coltitle=black, left=2mm, leftrule=.75mm, opacityback=0, opacitybacktitle=0.6, rightrule=.15mm, title=\textcolor{quarto-callout-tip-color}{\faLightbulb}\hspace{0.5em}{Tip}, titlerule=0mm, toprule=.15mm, toptitle=1mm]

Nesta etapa não será fornecido nenhum protocolo de identificação ou
modelo de planilha.

Cada grupo deverá decidir:

\begin{itemize}
\item
  como identificar os organismos;
\item
  quais informações registrar;
\item
  como organizar os dados;
\item
  qual formato utilizar para apresentar os resultados.
\end{itemize}

\end{tcolorbox}
